# Legal drafts

Drafts of the terms of use and the privacy policy, in Russian and Uzbek, for the lawyer to check (`DL-93` item 1, `DL-96` item 7). Nothing here is published by code: no migration or seeder reads these files.

| File | Document | Language |
|---|---|---|
| `terms.ru.txt` | Условия использования | Russian |
| `terms.uz.txt` | Foydalanish shartlari | Uzbek |
| `privacy.ru.txt` | Политика конфиденциальности | Russian |
| `privacy.uz.txt` | Maxfiylik siyosati | Uzbek |

## Format

The panel's plain format (`DL-94` item 1): a line starting with `## ` is a heading, a line starting with `- ` is a list item, any other line is a paragraph. Nothing is HTML. The "Редакция от" date is the moment of publication; it is not part of the text.

## Before publication

The square brackets are placeholders the Owner fills in (`DL-93` item 4):

- `[название компании]`, `[ИНН]`, `[юридический адрес]` (Uzbek: `[kompaniya nomi]`, `[STIR]`, `[yuridik manzil]`): the seller's details for the terms.
- `[срок — уточнит бухгалтер]` (Uzbek: `[muddat — buxgalter aniqlaydi]`): how many years order and money records are kept, from the accountant.

Then a lawyer in Uzbekistan checks both texts in both languages. The Admin publishes them on the panel's "Документы" page by pasting each file into its field and pressing "Опубликовать". The same texts then appear in the app (profile, sign-in screen) and at `/legal/terms` and `/legal/privacy` for Google Play.
