# Возрастной рейтинг (Content rating) — ответы анкеты IARC

Где: Play Console → **Контент приложения** (App content) → **Возрастные ограничения** (Content rating) → **Начать анкету** (Start questionnaire).

Анкета задаёт вопросы по очереди, и их формулировки Google меняет. Ниже ответ на каждую тему. Если встретится вопрос, которого здесь нет, пришлите скриншот — отвечу.

## Начало

| Поле | Ответ |
|---|---|
| Email address | ваш адрес для связи с IARC |
| Category | **All Other App Types** (Все остальные типы приложений): магазин физических товаров не игра, не соцсеть и не «магазин цифрового контента» |

## Вопросы

| Тема вопроса | Ответ | Почему |
|---|---|---|
| Насилие, кровь, оружие | **No** | Нет |
| Сексуальный контент, нагота | **No** | Нет |
| Грубые выражения | **No** | Нет |
| Наркотики, алкоголь, табак: упоминание, изображение или продажа | **No** | Ваше решение (вариант А, 2026-10-25): табака, насвая, вейпов и алкоголя в каталоге нет (`DL-116` (9)) |
| Азартные игры, симулированные азартные игры | **No** | Нет |
| Пугающий контент, грубый юмор | **No** | Нет |
| Пользователи общаются или обмениваются контентом с другими пользователями (Users interact) | **No** | Комментарии к заказу видят только сотрудники BarakaBozor; чатов, ленты и публичных отзывов нет |
| Приложение передаёт текущее местоположение пользователя другим пользователям (Shares location) | **No** | Курьер видит адрес доставки, а не текущее положение телефона покупателя |
| Покупка цифровых товаров (Digital purchases) | **No** | Продаются только продукты с доставкой, оплата наличными курьеру |
| Неограниченный доступ в интернет, веб-браузер (Unrestricted internet) | **No** | Приложение открывает только свой сервер и карты |
| Приложение — веб-браузер или поисковик | **No** | Нет |

## Ожидаемый итог

Самый низкий рейтинг во всех регионах (например, IARC 3+, PEGI 3, «Для всех»). Если итог выше, значит где-то стоит «Yes»: пришлите скриншот сводки.

## Когда отвечать заново

- в каталоге появятся товары 18+ (это решаете вы, отдельным вопросом, с проверкой возраста при доставке);
- появятся чат, публичные отзывы или онлайн-оплата цифровых услуг.
