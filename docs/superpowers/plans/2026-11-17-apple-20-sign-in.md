# Apple Stage 20 — «Вход» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sign-in as the test draws it: a labelled phone field with bold digits, a clear ×, a grey «Получить код» until nine digits that says how many are missing, Android's own-number sheet, no «Проверьте номер» window (the Owner's item), the consent right under the button with 44 px links and «…пришлём код в Telegram» in the subtitle; a code page that slides over the number and back, shows the number big with «Изменить», verifies the sixth digit by itself, pops digits under a blinking caret, offers «Вставить код», «Открыть Telegram» and a «Не пришёл код?» sheet; spinners with words, green boxes with ✓ and a buzz; a wrong code shakes red, clears and says how many tries are left (from the server); the lock is a big countdown and then «Получить новый код»; every refusal is a box with its way out; the name step has a label, a grey button until a letter and a grey «Войти с другим номером»; ✓ «Готово» leads to the home with a 4 s green welcome strip; large text keeps the button above the keyboard; the reader hears names, counts and outcomes.

**Architecture:** The server adds machine values to two refusals: a wrong code's `details.attempts_left` (sign-in and deletion share the check) and the send limit's `details.limit`. The client's `CodeLoginController` knows which action runs or failed, the tries left, a miss counter and the accepted moment; `SessionController.verifyCustomerCode` waits on a `beforeOpen` hook so ✓ shows before the router moves. The code route nests under `/auth` and is pushed (the platform's transition, `DL-124` (2)); back is «change the number». New sign-in pieces: `AuthNotice` (a refusal with its action), device helpers (`PhoneNumberHint` on `smart_auth`, `ClipboardCode`, `TelegramLauncher`), `CodeBoxes` looks, `LockCard`, the «Не пришёл код?» sheet, `WelcomeNotice` + the home's strip. `AuthScaffold` keeps a given key above the keyboard and drops the wordmark at large text; `ConsentLine` paints one paragraph with 44 px link targets.

**Tech Stack:** Laravel 13 + PostgreSQL (`RateLimiter`, feature tests); Flutter 3.47.5, flutter_riverpod 3.4.3, go_router 18 (nested route), url_launcher ^6.3.2, **smart_auth ^3.2.0 (new)**; core `SubmitButton`, `Shake`, `TimedBanner`, `showKitSheet`, `announce`, `textScaleAt`; flutter_test (`takeAnnouncements`, `meetsGuideline(iOSTapTargetGuideline)`, `NonlinearTextScaler`, `tester.view.viewInsets`, `SystemChannels.platform` mock for haptics and the clipboard).
