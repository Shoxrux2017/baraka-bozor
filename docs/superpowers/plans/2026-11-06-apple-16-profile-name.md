# Apple Stage 16 — «Профиль и имя» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The profile tab's darker green header is one button «Дилноза Каримова, +998 90 123 45 67 ›» (or «Как вас зовут?» with a white «Указать имя ›» pill) that opens the name editor, with the mode pill inside it when two sessions exist; the rows stand at once in groups «Аккаунт», «Приложение», «Помощь», with skeletons where data is still coming and an offline header «Не удалось загрузить профиль · Повторить»; «Мои адреса» shows «Дом», support reads «Позвонить в поддержку» with the number and a green call mark; «Выйти» is a red row that asks first and fades the sign-in in; the language sheet ticks the choice with a pop and closes after 0.3 s while the profile cross-fades. The name editor opens focused with the caret at the end, has ×, a grey frame and a grey helper, a button that stays grey until the name differs, a plain phone block, saves with the field frozen and the keyboard up, ends with ✓ «Имя сохранено» and a soft flash on the profile, checks a lost answer against the reloaded profile, says «Нет связи — имя не сохранено · Повторить», and asks «Сохранить новое имя?» on back. A screen reader meets the header as one button, group headings, «Русский, выбрано», the field with its helper as one stop and hears every outcome.

**Architecture:** Client only — no server field, no migration. Two core pieces come out of the rating's footer and serve both screens: `SubmitButton` (ready / off / busy / done faces with the ✓ pop) and `RetryStrip` (the red strip with «Повторить»). `SkeletonBar` gains a colour; a new core `EntranceFade` fades a screen's content in over white once, on request, and the sign-in uses it after a logout. The profile screen becomes one list in every state: `ProfileHeader` draws the loaded, loading and failed faces, the rows move to `profile_rows.dart`, the two sheets to `logout_sheet.dart` and `language_sheet.dart`. The name editor keeps `RenameController` and adds its own save phases, a freezing input formatter, the lost-answer check, a leave sheet and a `true` pop result that the profile header turns into an arrival flash.

**Tech Stack:** Flutter 3.47.5, flutter_riverpod 3.4.3, go_router 18.1.2; core `announce`, `Fold`, `SkeletonBar`, `textScaleAt`, `formatPhone`, `AccountMutation`, `NetworkFailure.mayHaveArrived` (`DL-134` (2)); addresses `deliveryAddressProvider`; legal `legalIndexProvider`; `HapticFeedback`; `lookupAppLocalizations`; flutter_test (`tester.takeAnnouncements()`, `tester.testTextInput`, `meetsGuideline(iOSTapTargetGuideline)`, `NonlinearTextScaler`).
